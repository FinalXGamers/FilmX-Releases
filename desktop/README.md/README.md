# FilmX desktop app

The FilmX desktop app opens the live FilmX website in its own application window. It needs an internet connection.

## Downloads

- Windows x64: NSIS installer
- macOS: universal Intel and Apple Silicon DMG (not signed or notarized)
- Linux x64: AppImage

The desktop app source is in the `desktop` folder. Choose **Actions → Build FilmX desktop apps → Run workflow** to build and publish installers to GitHub Releases. Enter the next version number, for example `1.0.0`.
